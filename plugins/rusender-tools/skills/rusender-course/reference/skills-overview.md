# Скиллы RuSender — снимок на 2026-09-02

**Это не источник истины.** Набор скиллов меняется: часть дорабатывается, появляются новые.
Актуальный список — на [rusender.ru/features/email/mcp](https://rusender.ru/features/email/mcp/)
или спроси прямо в чате: «какие скиллы для RuSender сейчас доступны».

Памятка, чтобы быстро вспомнить, какой скилл под какую задачу.

| Скилл | Для чего | Пример запроса | Цена запуска | Нужен выбор объекта | Демо для пустого аккаунта |
|---|---|---|---|---|---|
| `rusender-campaign-create` | Собирает рассылку от идеи до черновика; запуск — только после двойного подтверждения. **Единственный, который может реально отправить письмо людям** | «Создай рассылку про [тема]» | Средне | Список получателей | — |
| `rusender-campaign-report` | Отчёт по одной обычной рассылке: воронка, открытия по дням, клики, риски | «Разбери рассылку [название]» | Быстро | **Да**, рассылка | `assets/dashboard-template.html` |
| `rusender-ab-report` | Отчёт по A/B-тесту тем письма | «Покажи отчёт по A/B-тесту [название]» | Быстро | **Да**, A/B-кампания | `assets/dashboard-template.html` |
| `rusender-campaign-timeline` | Хроника всех отправок за всё время | «Покажи таймлайн рассылок» | Быстро | Нет | `assets/timeline-template.html` |
| `rusender-account-report` | Обзор всего аккаунта: база, объёмы, инфраструктура, лучшие рассылки | «Сделай обзор моего аккаунта» | **Долго** — примерно по 20–30 секунд на каждые 100 кампаний | Нет | `assets/dashboard-template.html` |
| `rusender-campaign-cleanup` | Архивирует заблокированные и отклонённые рассылки. **Меняет данные**, имеет собственный вопрос-подтверждение | «Убери в архив забаненные и отклонённые» | Быстро | Нет (спрашивает сам) | — |
| `rusender-ab-provider-test` | Экспериментальный: A/B-тест темы отдельно по Gmail, Mail.ru и Яндексу | «Протестируй темы по почтовым системам» | Средне | Список и темы | — |

Демо-файлы лежат внутри папки соответствующего скилла в `.claude/skills/`. Они показываются
**открытием файла**, а не вставкой в чат: самый большой весит 152 КБ.

Все скиллы требуют подключённого MCP RuSender (модуль 1) и работают только на реальных данных
аккаунта. Данные меняют только `rusender-campaign-create` (создаёт и отправляет) и
`rusender-campaign-cleanup` (архивирует) — остальные только читают.

## Чего пока нет в этом пакете

У RuSender есть и другие скиллы, которых здесь нет: дашборд по транзакционному ключу, разбор ядра
аудитории и пара экспериментальных. Скачать их можно на
[rusender.ru/features/email/mcp](https://rusender.ru/features/email/mcp/) — распаковать папку в
`.claude/skills/` и перезапустить `claude`.
