# Что можно делать с RuSender через чат

Справочник: что умеет MCP-подключение RuSender. Читай по диагонали — запоминать не нужно,
достаточно знать, что список существует, и заглядывать, когда встанет задача.

Формулировать вслух названия инструментов не надо. Ты пишешь обычными словами — Claude сам
выбирает, куда сходить.

---

## Часть 1. Посмотреть и посчитать

Ничего не меняет в аккаунте. Можно спрашивать сколько угодно и в любом порядке.

**Про рассылки**
- Узнать, как отработала любая рассылка: сколько доставлено, открыто, кликнуто, сколько отписалось
- Посмотреть, по каким ссылкам в письме кликали и какая собрала больше всего
- Увидеть, как расходились открытия по дням после отправки
- Разложить результат по почтовым системам: отдельно Gmail, отдельно Mail.ru, отдельно Яндекс
- Найти рассылку по названию, статусу или дате
- Посмотреть, какие рассылки заблокированы или отклонены модерацией
- Разобрать A/B-тест: какая тема победила и на сколько

**Про базу контактов**
- Узнать размер базы: сколько активных, сколько отписалось, сколько адресов битые
- Посмотреть, из чего состоят недоступные адреса: несуществующие, жалобы, временные сбои
- Найти конкретного контакта и посмотреть, что ему отправляли
- Посмотреть, какие есть списки и сколько в каждом контактов
- Посмотреть сегменты и по каким условиям они собраны

**Про настройки**
- Проверить, какие домены подключены и прошли ли они проверку
- Проверить, какие адреса отправителей подтверждены
- Посмотреть ключи для автоматических писем и их статус
- Посмотреть шаблоны писем, папки рассылок, переменные списков

---

## Часть 2. Сделать

Меняет данные в аккаунте. Каждое такое действие Claude делает только после твоего явного «да».

- Подключить домен и получить готовые DNS-записи, чтобы вставить их у хостера
- Добавить адрес отправителя (на него придёт письмо с подтверждением)
- Создать список и добавить в него контакты по одному
- Собрать письмо и рассылку целиком — от темы до вёрстки
- Запустить рассылку по-настоящему
- Завести ключ для автоматических писем
- Отправить автоматическое письмо — код, чек, уведомление
- Убрать в архив отклонённые и заблокированные рассылки
- Создать сегмент по условиям, переименовать список, разложить рассылки по папкам
- Отписать контакт или вернуть подписку обратно

## Часть 3. Чего через чат нельзя

Про это честно стоит знать заранее, чтобы не искать кнопку, которой нет.

- **Остановить или отменить уже запущенную рассылку.** Ни паузы, ни отмены среди инструментов нет.
  Отменить можно только в интерфейсе RuSender и только пока отправка не началась. Если отправка
  пошла — обращаться в поддержку.
- **Загрузить базу контактов файлом.** Массовый импорт делается в интерфейсе. Через чат контакты
  добавляются по одному — это нормально для теста, но не для базы на десять тысяч.
- **Узнать поимённо, кто открыл письмо.** Приходят суммы и разрезы: сколько, по каким доменам, по
  каким ссылкам. Списка людей нет.
- **Ускорить модерацию или проверку домена.** Это внешние процессы, они идут своим темпом.
- **Отправить тестовое письмо себе из черновика.** Кнопка теста живёт в интерфейсе RuSender.
- **Редактировать запущенную рассылку.** После старта поля не меняются — только черновик.
- **Создавать и редактировать цепочки писем.** Через чат доступен только их запуск для контакта.
